# session-meter

شريط فوق مكان الكتابة في Claude Code:

```
الموديل opus-5-5  ·  ⏱ المدة 12:34  ·  التوكنز 1.2 مليون (داخل 1.1 مليون / خارج 45.2 ألف)  ·  السياق 38٪  ·  التكلفة: الجلسة $1.234 · اليوم $4.100 · الأسبوع $18.20
حد 5 ساعات 63٪ ↻ يتجدد بعد 1س 30د ⚠ يخلص بعد ~50د  ·  حد الأسبوع 41٪ ↻ يتجدد بعد 3ي 4س
```

| الجزء | وش يعني |
| --- | --- |
| الموديل | الموديل الشغّال الحين |
| ⏱ المدة | مدة الجلسة |
| التوكنز | التوكنز اللي انصرفت في الجلسة (داخل / خارج، مع الكاش والوكلاء الفرعيين) |
| السياق | كم ممتلي من نافذة السياق |
| التكلفة | الجلسة · اليوم · آخر 7 أيام (عبر كل المحادثات) |
| حد 5 ساعات / حد الأسبوع | نسبة الاستهلاك، و ↻ الوقت لين يتجدد (ي = يوم، س = ساعة، د = دقيقة) |
| ⚠ يخلص بعد | بهالسرعة متى بيخلص الحد، لو بيخلص قبل ما يتجدد |

- يتلون أصفر من 70٪ وأحمر من 90٪.
- تنبيه لما أي حد يوصل 80٪ و95٪، ولما السياق يوصل 85٪ (يقترح `/compact`).
- الحدود تظهر مع اشتراك Pro/Max بعد أول رد في الجلسة.
- تكلفة اليوم والأسبوع تبدأ تنحسب من يوم تثبيت المود.

## الأوامر

- `/meter`: يخفي الشريط أو يظهره (ويتذكر اختيارك).
- `/meter autocompact on|off`: يسوي `/compact` تلقائي لما السياق يوصل 85٪.

## التثبيت

في Claude Code (الترمنال):

```
/plugin install session-meter --marketplace hz1mx/hz1mx-claude-mods
```

جاوب `y` واختر **user scope** عشان يشتغل في كل المحادثات.
